# Calculadora Visual

Calculadora desarrollada en java utilizando Swing y Apache NeatBeans.

## Caracteristicas

-Interfaz grafica
-Suma
-Resta
-Multiplicacion
-Division

## Tecnologias utilizadas

-Java
-Swing
-Apache NetBeans
-Apache Ant

1. Abrir el proyecto en Apache NetBeans.
2. Ejecuta el proyecto.
